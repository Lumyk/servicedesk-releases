# ServiceDesk for Mac

Release builds and the update feeds of ServiceDesk.

## Install

Open the [latest release](https://github.com/Lumyk/servicedesk-releases/releases/latest) and download the file for your Mac:

- Apple Silicon (M1 and later): the file ending in `-arm64.zip`
- Intel: the file ending in `-x86_64.zip`

Open the file, move ServiceDesk to Applications and launch it. Requires macOS 15 or later.

## Updates

The app updates itself: Settings → General → Check for Updates. `appcast-arm64.xml` and `appcast-x86_64.xml` in this repository are the signed update feeds it reads.
